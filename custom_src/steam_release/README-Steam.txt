FlatOut Ultimate Carnage - Chloe Collection Custom (Steam)

DEUTSCH
1. In Steam den normalen Spielzweig verwenden (Eigenschaften > Betas > Keine).
2. Bei der ersten Installation das Code-ZIP und das passende Assets-ZIP in
   denselben neuen Ordner ausserhalb des Spiels entpacken.
3. FlatOut schliessen und "Install or Update.bat" doppelklicken. Der Installer
   sucht die Steam-Installation. Bei Bedarf den Ordner mit Fouc.exe auswaehlen.
4. FlatOut wie gewohnt aus der Steam-Bibliothek starten.

Update: Das neue Code-ZIP in einen neuen Ordner entpacken und dieselbe BAT
starten. Das alte Assets-ZIP bleibt gueltig, solange der Release es nennt.
Bei einer neuen Assets-Version beide ZIPs entpacken und dieselbe BAT starten.
Profile, Spielstaende und Einstellungen im Spiel bleiben erhalten. Die
mitgelieferten Mod-Konfigurationen koennen sich durch Updates aendern.

Vanilla: Steam offen lassen und im Spielordner "FlatOut ohne Modpack
starten.bat" doppelklicken. Vanilla und Modpack verwenden getrennte Saves.
Nach dem Schliessen des Spiels aktiviert die BAT das Modpack wieder. Wurde
die BAT vorzeitig geschlossen, stellt ein erneuter Aufruf das Modpack wieder
her. DisplayFix und der mitgelieferte DXVK-Renderer bleiben aktiv.

ENGLISH
1. Use the normal Steam branch (Properties > Betas > None).
2. For a new installation, extract the Code ZIP and the matching Assets ZIP
   into the same new folder outside the game folder.
3. Close FlatOut and double-click "Install or Update.bat". Setup looks for
   the game. If prompted, select the folder containing Fouc.exe.
4. Start FlatOut normally from your Steam Library.

Updates: Extract the new Code ZIP into a new folder, then run the same BAT.
Reuse the current assets if the release lists the same Assets ZIP. If the
assets change, extract both new ZIPs and run the same BAT. Your profiles,
saves and in-game settings are kept. Bundled mod configuration may change.

Vanilla: With Steam open, double-click "FlatOut ohne Modpack starten.bat"
in the game folder. Vanilla and the mod use separate saves. The launcher
restores the mod after the game closes. If the launcher was closed early,
run it again to restore the mod. DisplayFix and the bundled DXVK stay active.

All Steam multiplayer participants should use the same modpack release.
